# 獅城步行誌：從自駕前哨站到人本空間

青年百億海外圓夢基金・築夢工場組企劃（賀昭恩）的現場記錄工具公開展示版。

- 線上瀏覽：https://chaoenho-hub.github.io/city-walk/
- 執行期間：2027 年 10 月 5 日至 25 日，新加坡 21 天
- 主軸：複合建築類型學。每個地點記為「元件＋關係＋屬性」的公式（例：CapitaSpring＝城市客廳＋熟食中心＋服務式公寓＋綠洲＋辦公＋空中花園），並自動畫出剖面簡圖。
- 四個分頁：觀點、路線（21 天日程、地圖、各地點案頭版公式與簡圖）、記錄（類型學記錄表與人本空間記錄表，可試用但不儲存）、手冊（類型學矩陣、組合統計、案例卡）
- 現場以 Claude 版田野工具記錄（只有本人可編輯），整理後同步到 `data/records.json` 與 `photos/`。
- 觀察只計人數與活動類型，不拍攝可辨識的面孔與車牌。
- 地圖位置為示意。
